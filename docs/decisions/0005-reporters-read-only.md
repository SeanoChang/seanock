# 0005 A worker that reports cannot write, and every worker sets its model

The verifier, the adversary, the planner and the scout hold reading tools
only, so a review cannot change the tree it judges. The builder and the scribe
write, and they cannot start agents. Each worker file names its model and
effort.

Rejected: one general worker with every tool. A reviewer that can edit will fix
what it should report, and a worker with no model line inherits the most costly
one.
